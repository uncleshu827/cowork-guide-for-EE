學習進度

嗨，EE 👋
來認識 Cowork

這份教學會帶你一步一步：從下載 app、登入、建立 Project，到讓 Claude 變成你的私人資料庫和提案產生器。
Cowork 是什麼？ 它是 Claude 桌面 app 上的三個模式之一（Chat / Cowork / Code）。Cowork 模式可以讀寫你電腦裡的檔案、操作 app、上網查資料、產出 Word / Excel / PPT，可以把它想成一個會操作電腦的智慧助理。

跟 ChatGPT / Claude 網頁版差在哪？ 網頁版只能在對話框裡聊天；Cowork 模式直接在你的電腦資料夾裡幫你做事，產出實體檔案。

它怎麼組織工作？ 用「Project」。每個 Project 對應一個你電腦上的資料夾。你可以建多個 Project（例如「事業資料庫」「家庭事務」「旅遊規劃」），它們各自獨立、互不干擾。

每完成一步就點旁邊的圓圈打勾 ✓，進度會自動存起來。
Step 1 / 10

先認識 Cowork 是什麼

在開始安裝之前，先花 30 秒看一下它跟你以前用過的東西差在哪。

1

它是一個「會操作你電腦」的助理

跟 ChatGPT 不同，Cowork 不只是回答你問題，它可以：

📝 幫你寫 Word / Excel / PPT 🗂️ 整理桌面或資料夾 📧 幫你看 Gmail 📅 排 Google Calendar 🌐 上網查資料 📊 做圖表跟報告
2

所有事情都用「中文跟它講」就好

不需要打程式、不需要學任何指令。就像跟一個人溝通一樣，例如：「幫我把桌面上有 2026 字樣的檔案，全部移到一個叫做『2026』的新資料夾」就可以了。

💡 小提醒
EE不用記任何技術名詞。整份教學唯一需要做的就是：跟著步驟做、有問題就直接問 Claude。Claude 會用中文回答你。

💡 為什麼按鈕叫 "Queue" 不叫 Send？
因為 Cowork 的任務會「排隊執行」——你可以連續丟好幾個任務給它，它會排隊一個個做。所以送出按鈕是 Queue（排入隊列）。對你來說操作上跟 Send 一樣，按下去就好。
Step 5 / 10

建立你的第一個 Project（最重要的觀念）

Project 是 Cowork 組織工作的方式。一個 Project = 一個資料夾 + 它記得的所有過往對話跟檔案。

1

先在你的電腦建一個資料夾

到桌面，按右鍵 → 「新增檔案夾」，命名為 我的工作區（之後可以改）。這個資料夾就是 Claude 唯一能讀寫的地方，外面的它都看不到。

✅ 為什麼不選整個 Documents？
三個原因：(1) 安全 — 限縮她能碰到的範圍。(2) 專注 — 她不會被一堆無關檔案搞混。(3) 整潔 — 你電腦原本的東西不會跟 AI 工作的成品混在一起。
2

在 Cowork 左邊欄點「Projects」→ 新增 Project

會跳出一個視窗請你：

  1. 取一個名字（例如「我的工作區」）
  2. 選擇這個 Project 對應的資料夾（剛剛在桌面建的那個）
  3. （可選）寫一段描述，告訴 Claude 這個 Project 是做什麼用的
3

Mac 會跳出權限視窗，按「允許」

Mac 系統會問「Claude 想存取『我的工作區』資料夾」，按 允許。這是 Mac 的安全機制，你之後也可以隨時收回（系統設定 → 隱私權與安全性 → 檔案與資料夾）。

4

恭喜，Project 建好了 🎉

從現在開始，當你在這個 Project 裡點「+ New task」開新任務，Claude 都會自動知道：

  • 她可以讀寫哪個資料夾
  • 這個 Project 過去的對話歷史
  • 你之前告訴她的習慣跟偏好
💡 可以建很多 Project
建議按用途分：例如「事業資料庫」「家庭事務」「旅遊規劃」「投資研究」各自一個 Project。彼此獨立、資料不會跑進別的 Project，找東西也快。
Step 6 / 10

第一個任務：做一份購物清單

跟著做一次，就會了。

1

進入剛才建的 Project

左邊欄點你的「我的工作區」Project。

2

點「+ New task」

左上方會有這個按鈕。點下去會開新的對話視窗。

3

把這段話貼進輸入框，按 Queue

📋 貼這段給 Claude
幫我做一份這週的買菜清單，分成「蔬菜」「肉類」「水果」「日用品」四類，每類列 5 樣常見的東西，存成一個 Excel 檔在這個 Project 的資料夾裡。

然後點右下的 Queue 按鈕（或按 Enter）送出。

4

看著 Claude 工作

她會開始一邊講話一邊操作。中間可能會問你「要不要繼續」或請你授權某個 app，按「允許 / 確認」就好。整個過程大概 30 秒到 1 分鐘。

5

打開檔案看成果

完成後她會在對話裡放一個藍色連結，點下去直接開檔。或者到桌面「我的工作區」資料夾，會看到一個 .xlsx 檔。

🎉 恭喜，你已經會用 Cowork 了
其它所有功能都是這個模式：「進 Project → 開 New task → 講你要什麼 → Queue → 在資料夾看到成果」。
Step 7 / 10

連接 Gmail、Google 日曆等工具

Cowork 可以接你的 Gmail、Google 日曆、Google Drive、Notion、Slack 等服務。連好之後她就能直接幫你看信、訂會議、找雲端文件，不用你複製貼上。

1

什麼是 Connector？

Connector = 把外部服務（Gmail、日曆等）「插上」Claude。連一次就好，之後她隨時可以幫你操作那個服務。

每個 Connector 都需要你親自登入 + 授權那個服務。授權的範圍由你決定，隨時可以收回。

2

怎麼連？點左邊欄的 Customize

左邊欄有一個 ⚙️ Customize（或叫 Settings → Connectors）的按鈕。點下去會看到一整排可連接的服務列表。

找到你想連的服務（例如 Gmail），點旁邊的 Connect。瀏覽器會自動打開，請你登入 Google 帳號 → 同意授權 → 自動跳回 Claude。

⚠️ 授權頁面要看清楚
Google 會顯示「Claude 想要存取以下權限：讀取 Gmail / 寄件 / 修改⋯⋯」。看完再按同意。如果有覺得不需要的權限可以取消，但有些功能就會用不了。
3

建議優先連這幾個

你不用一次全連，先連最常用的兩個（Gmail + Calendar）就會差很多：

📧 Gmail 最推薦
看信、找信、寫草稿、整理收件匣、把附件存到 Project
📅 Google Calendar 最推薦
看行事曆、訂會議、找空檔、生成會議準備包
📁 Google Drive
讀雲端的 Doc / Sheet / Slide，搬到 Project
📝 Notion
如果你有用 Notion 管理資料／筆記
4

連好之後可以叫她做這些事

點任何一個展開看實際範例句：

📧 Gmail：自動處理供應商來信

幫我看一下這個禮拜有哪些供應商寄信來，列出寄件人、主旨、重點摘要。然後把報價單或合約類的附件下載到 03_供應商 資料夾，依供應商名稱建子資料夾。

📅 Google Calendar：排會議跟提醒

幫我看一下下週的行事曆，找出有空的時段，安排一場 30 分鐘的客戶 call 在週二下午。把會議室訂下來，發邀請給 [客戶 email]。

📧 + 📅 跨工具：開會前的準備包

明天上午 10 點我跟某客戶有會議。請從行事曆抓出會議細節，從 Gmail 找這個客戶過去三個月的所有往來信件，從 Project 資料夾抓出我們提過給他的提案，整理成一份「會議準備包」存到 04_客戶提案/{客戶名}。

📧 Gmail：寫回覆草稿（不直接寄出）

幫我把收件匣裡這週還沒回覆的客戶來信整理出來，每一封幫我寫一份回覆草稿存到 Gmail 的「草稿匣」。語氣要客氣專業，重要的對方提問要明確回應。我之後會自己檢查跟寄出。

📁 Google Drive：把雲端資料納入 Project

我 Google Drive 裡有個叫「市場研究」的資料夾，幫我把裡面的所有檔案讀一遍，整理出 5 個關鍵洞察，存到 Project 的 01_市場研究 資料夾裡。

5

怎麼移除授權？

有兩個地方可以收回，建議兩邊都做最乾淨：

  1. 在 Claude 裡：Customize → Connectors → 找到那個服務 → Disconnect。
  2. 在 Google 帳號設定：到 myaccount.google.com/permissions → 找到 Claude → 移除存取權限。
🔒 隱私重點
Cowork 不會把你的信件、行事曆內容拿去訓練 AI。授權只是讓「這個 Claude 對話」可以幫你操作，跟你裝任何手機 app 給 Google 權限是一樣的概念。完整隱私政策在 anthropic.com/legal。
Step 8 / 10

更多可以叫她做的事

點任何一張卡片，會出現「可以怎麼跟 Claude 說」的範例句。直接複製貼上就能用。

📧

幫我寫一封 email

請假信、感謝信、客訴信、英文 email⋯⋯都可以。

幫我寫一封中文 email，跟同事說我下週一請假，請她幫我把午餐會議改到下週三同一時間。語氣客氣不囉嗦。
🗂️

整理桌面 / 資料夾

把混亂的檔案分類、改名、搬到對的位置。

這個 Project 資料夾裡有一堆 IMG_xxx 開頭的照片，幫我依照拍攝月份，分成不同的子資料夾整理好。
📊

做 Excel / 報表

列清單、做預算表、追蹤運動紀錄、月支出統計。

幫我做一個 12 個月的家庭收支記帳表，每個月有「收入、固定支出、變動支出、結餘」四欄，最下面自動加總。
📄

讀 PDF 並整理

把一份長 PDF 變成重點摘要或一頁式總結。

這份 PDF 是我女兒學校的活動通知，幫我整理出：日期、時間、地點、要帶什麼、要交多少錢，列成一個簡單的清單。
🎨

做一份簡報

把一個主題變成 5–10 頁的 PPT。

幫我做一份 8 頁的簡報，主題是「我家的義大利旅行回憶」，每頁一個城市，留空格讓我之後放照片。
🌐

幫我查資料

查餐廳、比價、找旅遊資訊、整理網路文章。

幫我查台北東區評價最好的 5 家義大利餐廳，比較它們的價位、招牌菜、營業時間，整理成一張表格。
★ Step 9 / 10 — 專為你設計

把 Cowork 當你的私人資料庫和提案產生器

你說想把市場研究、品牌資料、供應商報價這些零散的東西丟給她，請她抓重點、整理脈絡、產出商業提案——當你的「圖書館」。下面是針對這個工作流設計的五個步驟。

1

先設計一個資料夾結構（一次的事）

有條理的資料夾 = Claude 能精準找到東西。在你的 Project 資料夾裡建這個結構：

事業資料庫/
├─ 00_收件匣/         ← 還沒分類的東西先丟這
├─ 01_市場研究/
│   ├─ 產業趨勢/
│   └─ 消費者洞察/
├─ 02_品牌資料/
│   ├─ 我的品牌/      ← logo、定位、tone of voice
│   └─ 競品/
├─ 03_供應商/
│   └─ {供應商名}/    ← 報價單、聯絡資料、過往合作
├─ 04_客戶提案/
│   └─ {客戶名}/
└─ 05_過往交付/       ← 完成的提案、報告
💡 建議
檔名加日期前綴（例如 2026-05_某品牌_市場報告.pdf）會讓你之後問「上個月的某品牌資料」時超快找到。
2

在這個 Project 第一次對話時「教」Claude 認識你的事業

把下面這段改成你的版本，貼進去她會永久記得（記在這個 Project 裡）：

📋 自我介紹模板（改成你的）
請永久記住下面這些事：
1. 我做的是 XXX 產業，主要產品/服務是 YYY。
2. 目標客群是 ZZZ。
3. 品牌調性是 OOO（例：精緻、親民、專業、玩味⋯⋯）。
4. 常見的客戶類型是 AAA。
5. 我提案的格式偏好是 BBB（例：簡報 8–10 頁、開頭先放 TL;DR、附一頁時程跟報價）。
以後幫我寫東西的時候，請預設套用這些設定，不要每次都問。

這個動作做一次就好。在這個 Project 裡開新任務她也會記得。

3

把資料丟進對應的子資料夾

PDF、Word、PPT、Excel、甚至網頁截圖、會議錄音的逐字稿，都可以直接放。不用手動轉檔、不用先整理。雜亂沒關係，那就是 Claude 要幫你做的事。

4

五個你會用爆的指令

點任何一個展開看詳細範例：

① 抓出脈絡：把多份資料的共通點找出來

把 01_市場研究 資料夾裡這個月新加的 5 份報告全部讀過，整理出：(1) 三份以上共同提到的趨勢 (2) 各自獨特的觀點 (3) 對我的品牌最相關的 3 個訊號。輸出一份 1 頁的對照摘要存到 05_過往交付。

② 供應商比價：把報價單變成一張表

把 03_供應商 裡這次新收到的 4 家報價單，做成一張橫向比較表：欄位包含品項、單價、最低訂量、交期、付款條件、運費、備註。最後一欄給每家一個「綜合評分」跟你的推薦理由。存成 Excel。

③ 競品 dossier：把零散資料變成一份完整檔

常見問題

EE問過或可能會問的問題，先列在這。

它真的會看我電腦裡所有東西嗎？會不會不安全？

不會。每個 Project 只能看你親自指定給它的那個資料夾，外面的東西它讀不到也寫不到。Mac 第一次也會再問一次「要不要允許？」，是雙重把關。想停止隨時可以刪除 Project，或在 Mac「系統設定 → 隱私權與安全性 → 檔案與資料夾」收回權限。

免費帳號可以用 Cowork 嗎？

不行。Cowork 是 Pro / Max / Team 才能用。免費帳號只能用一般 Chat（純聊天）。建議先選 Pro $20/月，對你描述的用途（資料整理、寫提案、當資料庫）非常夠用。

它會記得我之前說過的事嗎？

同一個 Project 裡會記得（這就是 Project 的好處——它有記憶）。你跟它說「請永久記住⋯⋯」這類話，她會把這件事存到那個 Project 的記憶裡，新的 task 也會知道。但跨 Project 不會共享記憶（避免資料混淆）。

Scheduled 任務怎麼用？

左邊欄有「Scheduled」按鈕，可以看到所有排程任務。你不用自己學設定——直接跟 Claude 說「幫我建一個每週一早上 9 點的排程，做某某事」，她會幫你建好。建好之後你可以隨時編輯或關掉。

它會不會不小心刪掉我的檔案？

她要刪檔案前通常會先問你「確定要刪嗎？」並列出要刪的清單。最保險的做法是：第一個月先讓她在 Project 資料夾裡工作，重要的檔案先放外面、不要放進去；等熟悉之後再開放更大範圍。

說錯話、想叫它停下來怎麼辦？

輸入框旁邊會有一個停止按鈕（紅色方框），按下去她就會停。或直接打「停一下，我想改一下需求」她也會停下聽你說。

Opus / Sonnet / Haiku 三個模型差在哪？要選哪個？

輸入框右下會有模型選擇。簡單記：Opus = 最聰明但慢、最貴額度（適合寫提案、深度分析）；Sonnet = 平衡（日常用這個）；Haiku = 最快但最簡單（適合快速問答）。預設用 Sonnet 或 Opus 就好，Haiku 比較少用。

有問題卡住怎麼辦？

最簡單的方法：直接在對話框裡問 Claude。例如打「我不知道怎麼建 Project」、「我找不到下載的檔案」，她會用中文一步一步教你。她真的就是你的助理，問她沒關係。
